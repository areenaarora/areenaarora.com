# Journalism portfolio starter

Plain HTML and CSS, no packages or build step. This is unfinished placeholder content, not an example of completed reporting.

1. Copy `index.html` and `style.css` to the root of your own portfolio repository.
2. Replace every bracketed placeholder and set a real page title and description.
3. Choose three real entries. Label student work, experiments and work in progress accurately.
4. Add real project, methods and contact links where indicated by comments. Keep unfinished work unlinked; do not invent URLs or findings.
5. Use relative paths for local assets. Add images only with appropriate rights, meaningful alt text and optimised file sizes.
6. Test the page on mobile, with keyboard navigation and without your login.
7. Commit and push. In Settings → Pages, choose Deploy from a branch, your publishing branch (usually main) and / (root). Save, wait for deployment, then test the published URL.

GitHub Free supports Pages from public repositories. Do not commit confidential data or credentials. A project site normally uses `https://USERNAME.github.io/REPOSITORY/`; a user site uses a repository named `USERNAME.github.io`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
