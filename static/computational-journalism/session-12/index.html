Curate the work 23–26 min

Describe the question,
not just the toolkit.

Weak

“Used Python, Pandas, Matplotlib and AI to analyse a government dataset and create insightful visualisations.”

Stronger

“Analysed five years of district-level rainfall records to examine whether monsoon variability was increasing. Cleaned the data in Python, tested annual trends and built interactive charts. The analysis found substantial year-to-year variation but no consistent increase across all districts.”

Curate the work 26–28 min

Be specific about the work you did.

  • “Reported, analysed and wrote the story.”
  • “Cleaned the dataset and built the interactive visualisation.”
  • “Contributed mapping and data analysis to a team investigation.”
  • “Used AI for HTML/CSS and debugging; independently verified the data and wrote the reporting.”

“Built everything using AI-powered data journalism” leaves the role unclear.

Curate the work 28–30 min

Publish only what you can defend.

  • Project links work
  • Sources and methods are accurately described
  • Claims have supporting evidence
  • Collaborators are acknowledged
  • Unfinished work is labelled honestly

The previous class’s standard applies to claims about yourself, too.

Build & publish 39–42 min

From repository to a working URL

  • Create a repository; use a public repo for GitHub Free.
  • Add index.html, style.css and your real project links.
  • Commit and push the files.
  • Settings → Pages → Deploy from a branch.
  • Choose main → / (root) → Save.
  • Wait for deployment; open and test the published URL.

Keep learning 66–68 min

Give the tutorial a job.

Project-driven learning

Keep learning 68–70 min

A roadmap you can actually maintain

  1. Month 1

    Publish portfolio; clean up existing repositories.

  2. Month 2

    Reproduce a published chart from its source data.

  3. Month 3

    Publish a small original data story.

  4. Month 4

    Learn one technique for a reporting question.

  5. Month 5

    Collaborate or contribute to an existing project.

  6. Month 6

    Publish a stronger piece; replace a weaker entry.

An example, not a mandatory sequence. Adjust scope to time, access and reporting needs.
