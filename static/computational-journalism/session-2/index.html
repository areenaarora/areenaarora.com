Filtering is a checklist

Stage 1table
State TFR Kerala 1.7 Bihar 2.9 Tamil Nadu 1.6 UP 2.7 Goa 1.5
Stage 2question
TFR < 2 ?
Stage 3keep True
True False True False True
Resultrows kept
Kerala Tamil Nadu Goa

Filtering is simply creating a True/False checklist and keeping the rows marked True.

Reading Pandas like English

CodeMeaning
df.head()
Take the dataframe and show me the first five rows.
df.sort_values(...)
Take the dataframe, sort it, show the result.
df[df["x"] > 5]
Take the dataframe. Keep rows where x is greater than 5.

Debugging isn't failure

KeyError

Wrong column name.

NameError

Python doesn't recognise the name. Usually missing quotes or variable.

SyntaxError

Check brackets. Quotes. Parentheses.

Empty dataframe

Your code worked. No rows matched the condition.
